# Cosmic Royal: сайт наставниці Наталії

Сайт незалежної партнерки освітньої платформи GaliantPro: каталог рівнів і курсів, кошик з оплатою через WayForPay, особистий кабінет, чат з наставницею, AI-помічник на Claude, адмінка на сайті та адмін-бот у Telegram.

**Стек:** Next.js 15 (App Router), PostgreSQL + Prisma, Anthropic SDK, Telegram Bot API (без сторонніх бібліотек).

## Що вміє

| Частина | Де | Як працює |
|---|---|---|
| Каталог | `/courses`, `/courses/[slug]` | 7 рівнів і 25 курсів з цінами з офіційного сайту GaliantPro. Фільтр за напрямом, пошук, сортування |
| Кошик і оплата | `/cart`, `/api/checkout`, `/api/wayforpay/*` | Замовлення створюється на сервері (ціни беруться з бази, а не з браузера), підписана форма WayForPay, вебхук `serviceUrl` з перевіркою підпису та суми, ідемпотентний |
| Акаунти | `/register`, `/login`, `/account` | Email + пароль (bcrypt), сесія в httpOnly JWT-cookie. Кабінет: мої курси, інструкції доступу, історія замовлень |
| Чат з наставницею | віджет у кутку, `/support` | Повідомлення клієнта приходить адмінам у Telegram; відповідь **реплаєм** у Telegram з'являється в чаті на сайті. Працює і для гостей |
| AI-помічник | віджет, `/api/ai/chat` | Claude (`claude-sonnet-5-5`), каталог підставляється в системний промпт з бази. Не вигадує курсів і не обіцяє доходу, складне передає наставниці |
| Адмінка на сайті | `/admin` | Огляд і виручка, «чекають на доступ», замовлення, курси (CRUD, ціни, приховати), звернення з відповіддю, користувачі та ролі |
| Адмін-бот Telegram | `/api/telegram/webhook` | Сповіщення про оплати з кнопкою «✅ Доступ видано», `/stats`, `/orders`, `/support`, `/courses`, `/price slug 1490` і `/toggle slug` з підтвердженням |
| Пробні уроки | шапка, hero, банер, AI | Посилання на реферальну сторінку SmartSender (`NEXT_PUBLIC_TRIAL_URL`) |

Анімації: зоряне небо з падаючими зірками на canvas, плавна поява блоків при скролі, «дихаючий» декор і кристали, блиск золотих кнопок, анімований AI-маскот. Усе вимикається при `prefers-reduced-motion`.

## Локальний запуск

```bash
cp .env.example .env        # заповнити DATABASE_URL і AUTH_SECRET
npm install
npx prisma migrate deploy   # створити таблиці
npm run db:seed             # завантажити каталог
npm run dev
```

Першого адміна визначає `ADMIN_EMAILS`: зареєструйтеся з цим email, і акаунт отримає доступ до `/admin`.

## Деплой (рекомендовано Railway)

1. railway.app → New Project → Deploy from GitHub → цей репозиторій.
2. Додати сервіс **PostgreSQL**; у змінних сайту `DATABASE_URL = ${{Postgres.DATABASE_URL}}`.
3. Заповнити решту змінних з `.env.example`. `NEXT_PUBLIC_SITE_URL` = ваш домен (напр. `https://natalia-courses.com.ua`).
4. Start command: `npx prisma migrate deploy && npm run db:seed && npm start`.
5. Підключити свій домен у Settings → Domains.

Підійде також будь-який VPS з Node 20+ і PostgreSQL.

## WayForPay

1. У кабінеті WayForPay → Налаштування магазину: скопіювати **Merchant login** і **Merchant secret key** у `WAYFORPAY_MERCHANT_ACCOUNT` і `WAYFORPAY_SECRET_KEY`.
2. Домен сайту має бути доданий у магазин WayForPay (`WAYFORPAY_DOMAIN`, за замовчуванням береться з `NEXT_PUBLIC_SITE_URL`).
3. `serviceUrl` і `returnUrl` передаються автоматично з кожним платежем, окремо налаштовувати не треба.

Секретний ключ живе лише на сервері. Сервер приймає оплату тільки якщо підпис WayForPay правильний і сума збігається із замовленням.

## Telegram-бот

1. @BotFather → `/newbot` → токен у `TELEGRAM_BOT_TOKEN`.
2. `TELEGRAM_WEBHOOK_SECRET` = будь-який випадковий рядок.
3. Напишіть боту `/start`: він покаже ваш Telegram ID. Впишіть ID (через кому, якщо адмінів кілька) у `TELEGRAM_ADMIN_IDS` і перезапустіть сайт.
4. В адмінці на сайті натисніть «Підключити вебхук Telegram-бота».

Бот відповідає на команди лише адмінам зі списку. Сторонні люди бачать тільки привітання й посилання на сайт.

## AI-помічник

`ANTHROPIC_API_KEY` з console.anthropic.com. Модель задається через `AI_MODEL` (за замовчуванням `claude-sonnet-5-5`). Помічник бачить лише опубліковані курси, тож після зміни ціни чи опису в адмінці він одразу відповідає по-новому.

## Перед запуском

- [ ] Звірити тексти й умови з партнерським договором GaliantPro (використання назви, ціни, обіцянки в рекламі).
- [ ] Заповнити реквізити продавця (`NEXT_PUBLIC_SELLER_DETAILS`) та умови повернення в `/offer`; перевірити оферту й політику з юристом.
- [ ] Замінити портрет у блоці «Наставниця» на справжнє фото Наталії та дописати текст «про мене».
- [ ] Додати в адмінці «Інструкцію доступу» до кожного курсу (посилання на канал).
- [ ] Ціну «Бази постачальників» не вдалося прочитати з офіційного сайту, тож курс прихований. Вкажіть ціну в адмінці й увімкніть його.
- [ ] Відгуки на головну додавати лише справжні.
