# Cosmic Royal Site

**Status:** visual-reference assets in preparation. This repository was created as the destination for the independently layered implementation of the approved Cosmic Royal website concept.

## Source package

The full asset/source drop is delivered in the ChatGPT conversation as **`Cosmic_Royal_REFERENCE_LAYER_BREAKDOWN.zip`**. Extract the *contents* of the `Cosmic_Royal_REFERENCE_DECONSTRUCTED/` folder into the repository root.

The ZIP contains:

- `index.html`, `site.css`, `site.js` — working responsive HTML/CSS/JS layered composition.
- `assets/hero/heroine-cutout-alpha-preview.png` — experimental transparent portrait cutout, not a flawless extraction.
- `assets/hero/independent-gold-halo.svg`, `independent-foreground-clouds.svg`, `independent-star-cluster.svg` — independent vectors.
- `assets/decor/` — celestial ornaments and crystals.
- `assets/categories/`, `assets/covers/`, `assets/system/` — icons, covers and system pictograms.
- `docs/layer-map.json`, `docs/layer-map.csv` — source-screen layer boxes and mappings.
- `proof/site-desktop.png`, `proof/site-mobile.png`, `proof/approved-reference-annotated.jpg` — comparison visuals.

## Visual constraints

Only reconstruct the *left website* from the source mockup; the rightmost panel is a style-guide sidebar, not the website.

Use individual transparent assets over backgrounds with CSS positioning. **Never use the whole screenshot as the site background.** Keep all functional UI text and controls in HTML.

The original mockup is a flattened raster. Exact reconstruction of individual hair strands, crystals and star highlights is not guaranteed. Review portrait masking before production.

## Technical / product constraints

This package is **visual only**, not a deployed commerce solution. User registration, checkout/WayForPay webhooks, catalog synchronization, AI knowledge base, Telegram administration and real testimonials require separately approved backend work and partner rule verification.

Typography: Cormorant Garamond for display and Manrope for UI. Interface language: Ukrainian.
